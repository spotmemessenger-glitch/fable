## Recommended rebase procedure

1. `git rebase origin/master` on a **copy** of the branch, never in place.
2. `.handoff/NEXT-SESSION.md` → take **master's** side, every time.
3. `web/package.json` → **union** both test chains.
4. `rooms.gateway.ts` → resolve by hand. Keep master's `onJoin` in full
   (`verifyDmJoin`, `isDmRoom`, `Logger`, `peerId`); apply PR #2's extraction of
   `policy()`/`refuse()` into `RoomsAuthService`; confirm the gateway still
   *calls* the extracted service.
5. `socket-transport.js`, `db.js`, `reach.js` → union; verify no export is lost.
6. `node --check` every hand-edited JS file — this repo has caught a real
   mistake that way before.
7. Full suites: `npm test` + `npm run build` in `web`; `npx jest` +
   `npx tsc --noEmit` in `backend`.
8. **Document every resolution in the PR body**, per the standing instruction.
