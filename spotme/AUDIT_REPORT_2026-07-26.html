Critical Findings

CRITICAL: Video Persistence Bug

Impact: Data loss (entire chat history vanishes) | Root Cause: Unbounded media in localStorage

One 40 MB video + backlog → localStorage quota exceeded → error silently swallowed → entire room stops persisting → chat vanishes on refresh.

Fix: Remove media data before persist (store.js:stripDerived) | Timeline: 1 day

CRITICAL: Relay Rate Unverified

Impact: 10× cost swing (€24K–€300K/year) | Root Cause: Theory, never measured on real devices

All tests ran on localhost. Real NAT environment (mobile data ↔ broadband) unknown.

Fix: Cross-network hole-punch test on carrier-grade NAT | Timeline: 4–6 hours

HIGH: Biometric Data to Vendor (GDPR/BIPA Violation)

Voice cloning sends unencrypted audio to ElevenLabs. This is Article 9 special-category data (GDPR) and biometric data (Illinois BIPA: $1,000–$5,000 per violation).

Fix: Explicit consent modal + Privacy Policy update | Timeline: 4 hours

HIGH: Translation Pipeline — 7 Open Issues

Language detection gaps, UI deadlocks, stale caches, privacy leaks (persistent cache), unbounded API fan-out, edge cases (script detection), dead code.

Fix: Prioritize: privacy leak → language detection → deadlock → cache invalidation | Timeline: 14 hours

HIGH: No Error Tracking in Production

Live app at spotme-messenger.vercel.app has zero observability: no Sentry, no Datadog, no custom logging. Production issues invisible until user reports.

Fix: Install Sentry + wire error boundaries | Timeline: 8 hours
